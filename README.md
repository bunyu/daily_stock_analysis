# Daily Stock Analysis: Euronext Paris fork

AI-assisted daily analysis of a personal Euronext watchlist. Every trading day before the Paris open, a GitHub Actions run fetches prices, computes technical trends and key levels, searches recent news, asks an LLM for a decision dashboard, and pushes the report (Telegram and other channels).

This repository is a personal fork of [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis). The upstream project targets A-shares, Hong Kong and US stocks; this fork adds Euronext support and English output. The upstream documentation is still available in [`docs/README_EN.md`](docs/README_EN.md) and the [documentation index](docs/INDEX_EN.md).

> Reports are generated by a model from delayed public data. They are a technical and news reading aid, not investment advice.

## What this fork adds

| Area | Change |
| --- | --- |
| Euronext market | Yahoo Finance symbols with suffix `.PA` (Paris) and `.AS` (Amsterdam) are recognised as market `fr`: yfinance-only data, EUR, `XPAR` calendar in `Europe/Paris`, European prompt context (ECB, CAC 40, AMF). |
| Market review | `MARKET_REVIEW_REGION=fr` reviews CAC 40, SBF 120 and Euro Stoxx 50. |
| Multi-horizon analysis | Short, medium and long-term trend, 1M to 12M performance, 52-week range, and the nearest supports and resistances, computed from about 400 daily bars and shown in the report next to the model's Buy / Hold / Reduce view per horizon. |
| News search | French (or English) financial queries per stock, with curated sector and risk keywords for 17 watchlist names in [`src/data/euronext_stocks.py`](src/data/euronext_stocks.py). |
| Summary cards | One dark-theme image per stock (verdict, price plan, positives and risks, trend and forecast, key levels, reliability), saved to `reports/cards/` and sent to Telegram. `STOCK_CARD_IMAGES`, on by default in the workflow. |
| English reports | Workflow name, logs, report labels, number formats (K/M/B, ISO currency) in English. Reports are also printed on the run's Summary page. |
| Schedule | Mon-Fri 08:30 Europe/Paris through an external trigger, with a GitHub cron backup at 08:47 that skips itself when the day is already covered. |

## Quick start (GitHub Actions)

All settings live in **Settings -> Secrets and variables -> Actions** of the repository.

### 1. Required

| Name | Kind | Example |
| --- | --- | --- |
| `STOCK_LIST` | Variable | see the watchlist below |
| One LLM key, e.g. `GEMINI_API_KEY` or `ANTHROPIC_API_KEY` | Secret | see [`docs/LLM_CONFIG_GUIDE_EN.md`](docs/LLM_CONFIG_GUIDE_EN.md) |
| `REPORT_LANGUAGE` | Variable | `en` |
| `MARKET_REVIEW_REGION` | Variable | `fr` |

Watchlist used by this fork:

```
DCAM.PA,ASML.AS,BNP.PA,AIR.PA,EDEN.PA,ENGI.PA,ENX.PA,MC.PA,ORA.PA,OVH.PA,SAF.PA,SAN.PA,SU.PA,SOI.PA,STMPA.PA,HO.PA,TTE.PA
```

### 2. Recommended

| Name | Kind | Why |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Secrets | Receive the report on Telegram. Both are required. |
| `TAVILY_API_KEYS` or `BRAVE_API_KEYS` | Secret | News search. Without a search key the report has no news section. 17 stocks x 5 searches a day is about 1,900 searches a month, above Tavily's free 1,000; use several keys or Brave. |
| `STOCK_CARD_IMAGES` | Variable | `false` turns off the per-stock summary images (on by default in the workflow). |
| `STOCK_CARDS_ONLY` | Variable | `true` by default in the workflow: Telegram receives only the images, no text report or market review. Falls back to text if a card fails. Set `false` to get both. |
| `ANALYSIS_TIMEOUT_MINUTES` | Variable | Job timeout, default 30. Set `45` for the 17-stock watchlist. |

### 3. Run it

- Manual: **Actions -> Daily Stock Analysis -> Run workflow**. `mode=full` runs stocks plus market review; tick `force_run` to run on a non-trading day.
- Automatic at 08:30 Paris: follow [External 08:30 trigger](#external-0830-trigger).
- The report is sent to the configured channels and printed on the run's **Summary** page.

## External 08:30 trigger

GitHub's own scheduler can start a job hours late. The punctual trigger is therefore an external scheduler such as [cron-job.org](https://cron-job.org) calling the GitHub API.

1. GitHub -> Settings -> Developer settings -> **Fine-grained tokens**: create a token limited to this repository with **Actions: Read and write**.
2. In the scheduler, create a job, Mon-Fri at 08:30, time zone `Europe/Paris`:
   - Method `POST`, URL `https://api.github.com/repos/<owner>/daily_stock_analysis/actions/workflows/00-daily-analysis.yml/dispatches`
   - Headers `Authorization: Bearer <token>`, `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`
   - Body `{"ref":"main","inputs":{"mode":"full","force_run":"false"}}`
3. A successful call returns HTTP 204 and the run appears in the Actions tab.

The workflow keeps a GitHub cron at 08:47 Paris as a backup. Its `schedule-gate` job skips the backup when a dispatched run already succeeded or is still running that day, so there is never a duplicate report.

## Reading the report

Each stock section contains, in order:

1. **Core conclusion**: Buy / Hold / Reduce signal, one-sentence summary, and separate advice for investors with and without a position.
2. **Market snapshot**: last close, change, volume.
3. **Multi-Horizon Trend & Key Levels**:
   - Short term (days to 2 weeks): price against MA10 and MA20.
   - Medium term (1 to 3 months): MA20 against MA50.
   - Long term (6 to 12 months): MA50 against MA200.
   - Supports and resistances: clustered swing highs and lows of the last year, plus MA50, MA200 and the 52-week extremes, with the distance from the last close.
   - The model's own short-term and medium/long-term view.
4. **Data view, news, risks, catalysts and action checklist** from the upstream dashboard.

The trend table and the levels are computed by code (`src/multi_horizon.py`), not by the model, and the model is instructed to use those numbers for its buy zone, stop-loss and target.

## Adding or changing a stock

1. Find the Yahoo Finance symbol (`AI.PA` for Air Liquide, `ASML.AS` for ASML) and add it to `STOCK_LIST`. Any `.PA` / `.AS` symbol works without code changes and gets generic French search queries.
2. Optional, for better news: add a profile in [`src/data/euronext_stocks.py`](src/data/euronext_stocks.py) with a short name, sector keywords and risk keywords.

## Run locally

```bash
pip install -r requirements.txt
cp .env.example .env          # set STOCK_LIST, an LLM key, REPORT_LANGUAGE=en
python main.py --stocks MC.PA,TTE.PA
python main.py --market-review
python main.py --dry-run      # fetch data only, no LLM call
```

Checks before pushing:

```bash
./scripts/ci_gate.sh
python -m pytest -m "not network"
```
